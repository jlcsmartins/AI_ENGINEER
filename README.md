# 🚀 AI Engineer Roadmap & Estudos

Repositório dedicado ao registro prático, teórico e experimental da minha jornada de formação para me tornar um **AI Engineer (Engenheiro de Inteligência Artificial)**.

Aqui estão centralizados todos os exercícios, anotações conceituais, implementações de algoritmos, testes com modelos de linguagem e projetos aplicados de ponta a ponta.

---

## 🎯 Objetivo do Repositório

O propósito central deste projeto é construir uma base sólida e progressiva de habilidades para atuar na interseção entre **Ciência de Dados, Machine Learning e Engenharia de Software**, capacitando o desenvolvimento e sustentação de sistemas inteligentes modernos em ambientes de produção.

Os principais pilares de desenvolvimento são:
- Domínio da linguagem Python e das melhores práticas de engenharia de software e versionamento.
- Fundamentos matemáticos, estatísticos e computação científica de dados.
- Modelagem preditiva clássica e redes neurais profundas.
- Domínio em IA Generativa, Large Language Models (LLMs), RAG (Retrieval-Augmented Generation) e agentes autônomos.
- Engenharia de IA (MLOps/LLMOps), focando em APIs, conteinerização, escalabilidade, avaliação e monitoramento.

---

## 📂 Organização das Etapas de Estudo

O repositório está estruturado em módulos graduais que refletem a evolução do aprendizado:

```text
AI_ENGINEER/
├── 01-revisao/               # Fundamentos de programação e versionamento
│   ├── git-github/           # Git, branches, PRs e fluxos colaborativos
│   └── python/               # Sintaxe moderna, POO, tipagem e boas práticas
├── 02-matematica-dados/      # Manipulação de dados e bases analíticas
│   ├── estatistica/          # Probabilidade, estatística descritiva e inferência
│   ├── numpy/                # Computação matricial e álgebra linear aplicada
│   └── pandas/               # Tratamento, limpeza e exploração de dados
├── 03-machine-learning/      # Algoritmos supervisionados, não supervisionados e métricas
├── 04-deep-learning/         # Redes neurais, CNNs, RNNs e arquiteturas de Transformers
├── 05-ia-generativa/         # LLMs, Prompt Engineering, RAG, Embeddings e Agentes
├── 06-engenharia-ia/         # APIs (FastAPI), Docker, MLOps, LLMOps e deploy
└── projetos/                 # Aplicações práticas de ponta a ponta (portfólio)
```

## 📈 Como Acompanhar a Evolução

A evolução no repositório pode ser acompanhada através dos seguintes mecanismos:

1. **Checklist de Módulos (Progresso)**:
   - [ ] `01-revisao` (Python & Git/GitHub)
   - [ ] `02-matematica-dados` (NumPy, Pandas, Estatística)
   - [ ] `03-machine-learning` (Modelos preditivos clássicos)
   - [ ] `04-deep-learning` (Redes neurais e PyTorch)
   - [ ] `05-ia-generativa` (Aplicações com LLMs e RAG)
   - [ ] `06-engenharia-ia` (APIs, conteinerização e monitoramento)
   - [ ] `projetos` (Projetos práticos consolidados)

2. **Histórico de Commits e Versionamento**:
   - Cada novo conceito ou tópico prático concluído gera commits descritivos seguindo o padrão de *Conventional Commits* (ex.: `feat:`, `docs:`, `test:`).

3. **Documentação e Códigos em Cada Módulo**:
   - Cada diretório contará com seus próprios resumos conceituais e notebooks/scripts demonstrativos.

4. **Portfólio na pasta `projetos/`**:
   - Aplicações integradas de fim a fim, acompanhadas de demonstrações, instruções de execução e relatórios de métricas.
